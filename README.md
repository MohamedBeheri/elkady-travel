# نظام إدارة النقل الجامعي والرحلات السياحية

نظام متكامل لإدارة نقل الطلاب الجامعي (اشتراكات ترم/شهري/يومي) والرحلات السياحية الخاصة،
بنفس معمار مشاريع عيادة الأسنان و Golden Cafe.

- **الواجهة الخلفية:** Django 5 + Django REST Framework + JWT (SimpleJWT)
- **الواجهة الأمامية:** React 19 + TypeScript + Vite + Ant Design (RTL عربي) + RTK Query
- **قاعدة البيانات:** SQLite محلياً / PostgreSQL على Render
- **النشر:** خدمة واحدة (Django يخدم الـ SPA + API + الوسائط)
- **البورتات:** الخلفية `8025` / الأمامية `5185`

## التشغيل المحلي

### الخلفية
```bash
cd backend
python3.11 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo      # بيانات تجريبية + حسابات
python manage.py runserver 127.0.0.1:8025
```

### الأمامية
```bash
cd frontend
npm install
npm run dev                     # http://localhost:5185
```

## المنطق التشغيلي الأساسي (محرك التخصيص)
- **الأولوية:** ترم > شهري > يومي (`apps/operations/services.py`).
- داخل كل فئة: الترتيب بحسب **وقت الطلب الدقيق**.
- **لا يتجاوز التخصيص سعة الرحلة أبداً** — العملية **ذرّية (transactional)** مع قفل صف الرحلة لمنع الحجز المزدوج.
- الإلغاء **يحرّر المقعد** ويُرقّي التالي في قائمة الانتظار تلقائياً.
- **إثبات الدفع لا يعني التأكيد** — يتطلب موافقة الإدارة.
- الاشتراك المؤكد يظهر تلقائياً في كشوف الركاب (مجمّعة حسب المسار/الوجهة/الموعد/نقطة الالتقاط/الجامعة).
- السياحة: طلب ← عرض سعر ← قبول/رفض العميل (مسار منفصل تماماً).

## الوحدات (Apps)
- `users` — المستخدمون والأدوار (مدير/نقل/مدفوعات/تشغيل/سياحة/طالب) + التسجيل.
- `config_app` — الوجهات، الجامعات، المسارات، نقاط الالتقاط، المواعيد، السعات، الأسعار، وسائل وحسابات الدفع.
- `bookings` — الاشتراكات + إثبات الدفع + طابور مراجعة الإدارة.
- `operations` — الرحلات اليومية، قائمة الانتظار، محرك تخصيص المقاعد، رحلات العودة، كشوف الركاب.
- `tourism` — طلبات الرحلات الخاصة وعروض الأسعار.
- `notifications` — الإشعارات داخل التطبيق (قابل للتوسعة لـ SMS/WhatsApp/Email).

## النشر على Render
البناء عبر `render.yaml` + `backend/build.sh` (يبني الأمامية، يجمع الملفات الثابتة، يهاجر، ويزرع البيانات مرة واحدة).
